# InnoBot RFID Access Control System | سیستم کنترل تردد RFID با برد اینوبات

پروژه سیستم کنترل ورود و خروج کارمندان با استفاده از ماژول **MFRC522 RFID** و برد آموزشی **InnoBot**. این پروژه امکان احراز هویت کارت‌ها و مدیریت کاربران (افزودن، جایگزینی و حذف تگ‌های کارمندان توسط کارت مدیر) را از طریق نمایشگر و کلیدهای روی برد فراهم می‌کند.

---

## ✨ ویژگی‌ها (Features)
* **سطح دسترسی دوگانه:** تشخیص کارت مدیر (`Boss`) برای ورود به پنل تنظیمات و کارت کارمندان (`Employee`) برای باز کردن قفل.
* **مدیریت کاربران بدون نیاز به کامپیوتر:** امکان تعریف یا حذف تا ۳ کارت کارمند مستقیماً از طریق منوی LCD و دکمه‌های برد.
* **تایم‌اوت هوشمند (Auto-Timeout):** خروج خودکار از منوی تنظیمات پس از ۱۰ ثانیه عدم فعالیت جهت حفظ امنیت.
* **هشدار امنیتی:** نمایش پیغام خطا برای کارت‌های ناشناس یا حذف‌شده.

## 🎮 راهنمای کار با منوی تنظیمات (Menu Navigation)

پس از نزدیک کردن **کارت مدیر (Master Card)** به ماژول، وارد منوی مدیریت می‌شوید:

* **کلید ۱ (`SW1`):** ثبت تگ جدید یا جایگزینی تگ فعلی (`Change Tag`)
* **کلید ۲ (`SW2`):** حذف تگ کارمند انتخاب‌شده (`Remove Tag`)
* **کلید ۳ (`SW3`):** رفتن به اسلات کارمند بعدی (`Next ID: 1 -> 2 -> 3`)
* **کلید ۴ (`SW4`):** لغو عملیات / خروج از منوی تنظیمات (`Exit / Cancel`)
